# 视频播放器多端部署（大小屏适配）与自由流转功能 实现方案

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- ]`) syntax for tracking.

**Goal:** 为现有 HarmonyOS 视频播放器应用增加多端部署（手机/平板/大屏自适应）和自由流转（跨设备无缝接续播放）能力。

**Architecture:** 多端适配采用 ArkUI 断点系统 + 栅格布局 + 响应式组件，根据窗口宽度自动切换布局策略（sm/md 竖屏手机布局、lg 平板/大屏横屏布局）。自由流转采用 UIAbility Continuation 机制，源端通过 `onContinue()` 保存播放状态，对端通过 `onCreate()/onNewWant()` 恢复播放。

**Tech Stack:** HarmonyOS 6.0.2 (API 12), ArkTS, ArkUI GridRow/GridCol, BreakpointSystem, UIAbility Continuation, @kit.AbilityKit

### 2.1 适配策略

| 断点 | 窗口宽度 | 设备类型 | 布局策略 |

#### Task 3: 创建断点管理器

**文件:** 新建 `entry/src/main/ets/common/BreakPointManager.ets`

监听窗口尺寸变化，计算当前断点并写入 AppStorage：

```typescript
import { window } from '@kit.ArkUI';
import { BreakPointConstants } from './BreakPointConstants';

export class BreakPointManager {
  private windowObj: window.Window | undefined = undefined;

  /**
   * 初始化断点监听
   * 在 EntryAbility.onWindowStageCreate 中调用
   */
  async init(windowStage: window.WindowStage): Promise<void> {
    try {
      this.windowObj = await windowStage.getMainWindow();
      // 获取初始窗口尺寸并设置断点
      const windowProperties = await this.windowObj.getWindowProperties();
      this.updateBreakPoint(windowProperties.windowRect.width);
      // 监听窗口尺寸变化
      this.windowObj.on('windowSizeChange', (windowSize: window.Size) => {
        this.updateBreakPoint(windowSize.width);
      });
    } catch (error) {
      console.error(`BreakPointManager init failed: ${error.code}, ${error.message}`);
    }
  }

  private updateBreakPoint(windowWidth: number): void {
    let currentBreakpoint: string = BreakPointConstants.SM;
    if (windowWidth >= BreakPointConstants.MD_THRESHOLD) {
      currentBreakpoint = BreakPointConstants.LG;
    } else if (windowWidth >= BreakPointConstants.SM_THRESHOLD) {
      currentBreakpoint = BreakPointConstants.MD;
    }
    AppStorage.setOrCreate(BreakPointConstants.BREAK_POINT_KEY, currentBreakpoint);
  }

  /**
   * 释放监听
   */
  release(): void {
    if (this.windowObj) {
      this.windowObj.off('windowSizeChange');
    }
  }
}
```

#### Task 10: 在 VideoPlayViewModel 中添加状态序列化/反序列化

**文件:** 修改 `entry/src/main/ets/viewmodel/VideoPlayViewModel.ets`

```typescript
/**
 * 流转数据接口
 */
export interface ContinueData {
  chooseNumber: number;
  currentTime: number;
  durationTime: number;
  chooseSpeed: number;
  speedText: string;
  playState: number;  // PlayerState 枚举值
  ambientLightEnabled: boolean;
  ambientLightColor: string;
}

/**
 * 序列化当前播放状态（用于跨端迁移）
 */
serializeContinueData(): ContinueData {
  return {
    chooseNumber: this.chooseNumber,
    currentTime: this.currentTime,
    durationTime: this.durationTime,
    chooseSpeed: this.chooseSpeed,
    speedText: typeof this.speedText === 'string' ? this.speedText : '',
    playState: this.playState,
    ambientLightEnabled: false,  // 氛围灯状态由 View 层管理
    ambientLightColor: this.ambientLightColor,
  };
}

/**
 * 从流转数据恢复状态（不自动播放，等待用户操作）
 */
restoreFromContinueData(data: ContinueData): void {
  this.chooseNumber = data.chooseNumber;
  this.currentTime = data.currentTime;
  this.durationTime = data.durationTime;
  this.chooseSpeed = data.chooseSpeed;
  this.playState = PlayerState.PAUSE;  // 恢复后先暂停
  this.ambientLightColor = data.ambientLightColor;
}
```

#### Task 11: 修改 EntryAbility 实现流转逻辑

**文件:** 修改 `entry/src/main/ets/entryability/EntryAbility.ets`

```typescript
import { AbilityConstant, ConfigurationConstant, UIAbility, Want } from '@kit.AbilityKit';
import { hilog } from '@kit.PerformanceAnalysisKit';
import { window } from '@kit.ArkUI';
import { BreakPointManager } from '../common/BreakPointManager';

const DOMAIN = 0x0000;
const TAG = 'ENTRY';

export default class EntryAbility extends UIAbility {
  private breakPointManager: BreakPointManager = new BreakPointManager();

  onCreate(want: Want, launchParam: AbilityConstant.LaunchParam): void {
    try {
      this.context.getApplicationContext().setColorMode(
        ConfigurationConstant.ColorMode.COLOR_MODE_NOT_SET
      );
      hilog.info(DOMAIN, TAG, '%{public}s', 'Ability onCreate');

      // 检查是否为流转恢复
      if (launchParam.launchReason === AbilityConstant.LaunchReason.CONTINUATION) {
        this.handleContinuation(want);
      }
    } catch (error) {
      hilog.error(0x0000, TAG, `onCreate catch error, code: ${error.code}, message: ${error.message}`);
      return;
    }
  }

  /**
   * 源端：保存迁移数据
   */
  onContinue(wantParam: Record<string, Object>): AbilityConstant.OnContinueResult {
    hilog.info(DOMAIN, TAG, '%{public}s', 'Ability onContinue');

    try {
      // 从 AppStorage 获取 ViewModel 保存的流转数据
      const continueDataStr = AppStorage.get<string>('continueData');
      if (continueDataStr) {
        wantParam['continueData'] = continueDataStr;
        hilog.info(DOMAIN, TAG, `Continue data saved, length: ${continueDataStr.length}`);
        return AbilityConstant.OnContinueResult.AGREE;
      }
      // 没有可迁移的数据也同意（用户可能在首页未播放）
      return AbilityConstant.OnContinueResult.AGREE;
    } catch (error) {
      hilog.error(DOMAIN, TAG, `onContinue error: ${error.code}, ${error.message}`);
      return AbilityConstant.OnContinueResult.REJECT;
    }
  }

  /**
   * 对端：恢复迁移数据
   */
  private handleContinuation(want: Want): void {
    hilog.info(DOMAIN, TAG, '%{public}s', 'Handling continuation restore');

    if (want.parameters !== undefined) {
      const continueDataStr = want.parameters['continueData'] as string;
      if (continueDataStr) {
        AppStorage.setOrCreate('restoreContinueData', continueDataStr);
        hilog.info(DOMAIN, TAG, 'Continue data restored from source device');
      }
    }

    // 设置迁移状态为 ACTIVE
    this.context.setMissionContinueState(AbilityConstant.ContinueState.ACTIVE);
  }

  onWindowStageCreate(windowStage: window.WindowStage): void {
    hilog.info(DOMAIN, TAG, '%{public}s', 'Ability onWindowStageCreate');

    // 初始化断点管理
    this.breakPointManager.init(windowStage);

    windowStage.loadContent('pages/Index', (err) => {
      if (err.code) {
        hilog.error(DOMAIN, TAG, 'Failed to load the content. Cause: %{public}s', JSON.stringify(err));
        return;
      }
      hilog.info(DOMAIN, TAG, 'Succeeded in loading the content.');
    });

    try {
      windowStage.on('windowStageEvent', (data) => {
        if (data === window.WindowStageEventType.RESUMED) {
          this.context.eventHub.emit('onForeground');
        } else if (data === window.WindowStageEventType.PAUSED) {
          this.context.eventHub.emit('onBackground');
        }
      });
    } catch (error) {
      hilog.error(0x0000, TAG, `windowStageEvent catch error, code: ${error.code}, message: ${error.message}`);
      return;
    }
  }

  onForeground(): void {
    hilog.info(DOMAIN, TAG, '%{public}s', 'Ability onForeground');
    // 前台时保存最新的流转数据到 AppStorage
    this.saveContinueData();
  }

  /**
   * 将当前播放状态保存到 AppStorage（供 onContinue 读取）
   */
  private saveContinueData(): void {
    try {
      const viewModel = AppStorage.get<VideoPlayViewModel>('videoPlayViewModel');
      if (viewModel && viewModel.isUse) {
        const data = viewModel.serializeContinueData();
        AppStorage.setOrCreate('continueData', JSON.stringify(data));
        hilog.info(DOMAIN, TAG, 'Continue data saved to AppStorage');
      }
    } catch (error) {
      hilog.error(DOMAIN, TAG, `saveContinueData error: ${error.code}, ${error.message}`);
    }
  }

  onDestroy(): void {
    this.breakPointManager.release();
    hilog.info(DOMAIN, TAG, '%{public}s', 'Ability onDestroy');
  }
}
```

```typescript
import { resourceManager } from '@kit.LocalizationKit';
import { hilog } from '@kit.PerformanceAnalysisKit';
import { VideoPlayView } from '../view/VideoPlayView';
import { VideoPlayViewModel, ContinueData } from '../viewmodel/VideoPlayViewModel';
import { ThemeColors } from '../common/ThemeColors';
import { BreakPointConstants } from '../common/BreakPointConstants';

const VIDEO_NAMES = ['1.mp4', '2.mp4', '3.mp4'];
const TAG = 'INDEX';

@Entry
@Component
struct Index {
  @State videoResources: resourceManager.RawFileDescriptor[] = [];
  @State viewModel: VideoPlayViewModel = new VideoPlayViewModel();
  @State isFullScreen: boolean = false;
  @Provide('isDarkTheme') isDarkTheme: boolean = true;
  @Provide('themeColors') themeColors: ThemeColors = new ThemeColors(true);
  @StorageProp(BreakPointConstants.BREAK_POINT_KEY) currentBreakpoint: string = BreakPointConstants.SM;

  toggleTheme(): void {
    this.isDarkTheme = !this.isDarkTheme;
    this.themeColors = new ThemeColors(this.isDarkTheme);
  }

  aboutToAppear(): void {
    try {
      this.videoResources.length = 0;
      for (let i = 0; i < VIDEO_NAMES.length; i++) {
        let rawDes = this.getUIContext().getHostContext()?.resourceManager.getRawFdSync(VIDEO_NAMES[i]);
        if (rawDes) {
          this.videoResources.push(rawDes);
        }
      }
    } catch (error) {
      hilog.error(0x0000, TAG, `aboutToAppear catch error, code: ${error.code}, message: ${error.message}`);
    }

    // 将 ViewModel 存入 AppStorage（供 EntryAbility 保存流转数据）
    AppStorage.setOrCreate('videoPlayViewModel', this.viewModel);

    // 检查是否有流转恢复数据
    this.checkAndRestoreContinueData();
  }

  /**
   * 检查并恢复流转数据
   */
  private async checkAndRestoreContinueData(): Promise<void> {
    try {
      const restoreDataStr = AppStorage.get<string>('restoreContinueData');
      if (restoreDataStr) {
        const data: ContinueData = JSON.parse(restoreDataStr) as ContinueData;
        hilog.info(DOMAIN, TAG, `Restoring from continuation: videoIndex=${data.chooseNumber}, time=${data.currentTime}`);

        // 先让 ViewModel 初始化
        this.viewModel.videoSources = this.videoResources;
        this.viewModel.setUIContext(this.getUIContext());
        await this.viewModel.initialize();

        // 恢复状态
        this.viewModel.restoreFromContinueData(data);

        // 重新加载对应视频并 seek 到之前的位置
        if (data.chooseNumber >= 0 && data.chooseNumber < this.videoResources.length) {
          const newState = await this.viewModel.onVideoSelected(data.chooseNumber, this.videoResources[data.chooseNumber]);
          if (newState !== null) {
            this.viewModel.playState = newState;
            // seek 到之前的播放位置
            if (data.currentTime > 0) {
              await this.viewModel.performSeek(data.currentTime);
              // 恢复后暂停，等待用户操作
              this.viewModel.playState = this.viewModel.togglePlayPause(this.viewModel.playState);
            }
          }
        }

        // 清除恢复数据标记
        AppStorage.delete('restoreContinueData');
        hilog.info(DOMAIN, TAG, 'Continuation restore completed');
      }
    } catch (error) {
      hilog.error(DOMAIN, TAG, `checkAndRestoreContinueData error: ${error.code}, ${error.message}`);
    }
  }

  aboutToDisappear(): void {
    try {
      for (let i = 0; i < VIDEO_NAMES.length; i++) {
        this.getUIContext().getHostContext()?.resourceManager.closeRawFdSync(VIDEO_NAMES[i]);
      }
    } catch (error) {
      hilog.error(0x0000, TAG, `aboutToDisappear catch error, code: ${error.code}, message: ${error.message}`);
    }
  }

  onBackPress(): boolean | void {
    if (this.isFullScreen) {
      this.isFullScreen = false;
      return true;
    }
    return false;
  }

  build() {
    Column() {
      VideoPlayView({
        viewModel: this.viewModel,
        videoSources: $videoResources,
        isFullScreen: this.isFullScreen,
        currentBreakpoint: this.currentBreakpoint
      });
    }
    .width('100%')
    .height('100%')
    .backgroundColor(this.themeColors.pageBackground)
  }
}
```

## 五、风险与注意事项

1. **Native 层兼容性**：`libplayer.so` 编译了 `arm64-v8a` 和 `x86_64` 两种 ABI，平板（通常也是 arm64）可正常运行。如需支持 x86 平板需确认 ABI 覆盖。

2. **流转数据量限制**：`onContinue` 的 `wantParam` 数据需控制在 100KB 以下。当前方案仅传递轻量播放状态（JSON 约 200 字节），远低于限制。

3. **模拟器不支持**：自由流转功能暂不支持模拟器调试，需要两台真机（同一华为账号、同一 WLAN/蓝牙网络）。

4. **XComponent 重建**：流转到对端后，XComponent 需要重新创建 Surface，Native Player 也需重新初始化。当前方案通过 `onVideoSelected` 重新创建 Player 来处理。

5. **弹幕不迁移**：为简化实现，弹幕列表不随流转迁移（弹幕是临时 UI 状态，非核心播放数据）。
