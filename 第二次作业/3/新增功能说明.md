## 二、弹幕功能

### 2.1 功能描述

弹幕功能允许用户在观看视频时发送实时评论文字，文字以滚动形式从右向左飘过视频画面，营造互动氛围。

### 2.2 核心特性

#### 2.2.1 多轨道并行显示
- 弹幕分布在 **5 条独立轨道** 上，避免文字重叠
- 轨道高度自动计算，均匀分布在视频上半区域
- 每条轨道独立管理，互不影响

#### 2.2.2 平滑移动效果
- 基于 **时间差分算法** 计算位移，确保不同帧率下速度一致
- 默认速度：**35% 屏幕宽度/秒**
- 支持倍速联动：视频倍速播放时，弹幕速度自动同步

#### 2.2.3 颜色自定义
- 提供 **8 种预设颜色**：白、红、橙、黄、绿、青、蓝、紫
- 颜色选择面板支持展开/收起
- 选中颜色实时预览

#### 2.2.4 输入与发送
- 底部输入框支持文字输入
- 点击"发送"按钮或键盘确认键发送
- 发送后输入框自动清空

### 2.4 数据结构

```typescript
interface DanmakuItem {
  id: string;        // 唯一标识符
  text: string;      // 弹幕文字内容
  color: string;     // 文字颜色（Hex格式）
  left: number;      // 水平位置（百分比）
  top: number;       // 垂直位置（百分比）
}
```

### 2.5 核心算法

#### 位置更新算法
```typescript
// 计算时间差（毫秒）
const deltaMs = now - lastTimestamp;

// 计算位移（百分比）
const speedPercentPerSecond = 35;
const deltaPercent = (speedPercentPerSecond * deltaMs) / 1000;

// 更新位置
item.left = item.left - deltaPercent;

// 移除超出屏幕的弹幕
if (item.left < -20) remove(item);
```

#### 轨道分配算法
```typescript
const trackCount = 5;
const trackIndex = danmakuList.length % trackCount;
const topPercent = 8 + trackIndex * 6; // 8%, 14%, 20%, 26%, 32%
```

## 三、氛围灯功能

### 3.1 功能描述

氛围灯功能在视频播放器边缘渲染动态光晕效果，光晕颜色跟随视频内容变化，营造沉浸式观影体验。

### 3.2 核心特性

#### 3.2.1 边缘光晕效果
- 光晕出现在视频 **四边外围**，**不遮挡视频内容**
- 采用 **渐变透明** 设计，从实色渐变到完全透明
- 使用 **高斯模糊** 营造柔和光晕感

#### 3.2.2 动态颜色变化
- 颜色每 **2 秒** 自动切换
- 支持 **8 种颜色循环**：橙、蓝、粉、绿、紫、黄、红、青
- 控制面板实时显示当前颜色

#### 3.2.3 智能尺寸适配
- **非全屏模式**：光晕厚度 12vp，模糊半径 15
- **全屏模式**：光晕厚度 20vp，模糊半径 15
- 自动适配屏幕方向变化

#### 3.2.4 开关控制
- 独立开关按钮（💡 图标）
- 支持展开/收起控制面板
- 状态持久化（当前播放会话内）

### 3.3 界面布局

```
        ↑ 顶部光晕（渐变橙色）
        │
   ←────┼────┼────┼────┼────┼────→
        │    │    │    │    │

```

### 3.4 技术亮点

#### 3.4.1 双层布局防遮挡
```
外层 Stack (clip: false)          ← 氛围灯在此层，可溢出
  ├── 氛围灯视图（大尺寸）
  └── 内层 Stack (clip: true)     ← 视频在此层，严格裁剪
       ├── XComponent (视频)
       ├── 弹幕层
       └── 控制层
```

#### 3.4.2 渐变颜色定义
```typescript
// 从实色渐变到透明
linearGradient({
  direction: GradientDirection.Bottom,
  colors: [
    ['rgba(255,102,0,0.7)', 0.0],  // 70% 透明度橙色
    ['rgba(255,102,0,0.3)', 0.3],  // 30% 透明度
    ['rgba(0,0,0,0)', 1.0]          // 完全透明
  ]
})
```

#### 3.4.3 状态共享机制
使用 `@Provide` / `@Consume` 装饰器实现跨组件状态共享：

```typescript
// VideoPlayView.ets 中提供状态
@Provide('ambientLightEnabled') ambientLightEnabled: boolean = false;
@Provide('ambientLightColor') ambientLightColor: string = '#FF6600';

// 子组件中消费状态
@Component
struct AmbientLightView {
  @Consume('ambientLightEnabled') ambientLightEnabled: boolean;
  @Consume('ambientLightColor') ambientLightColor: string;
}
```

#### 4.1.2 关键方法

**添加弹幕**
```typescript
sendDanmaku(text?: string): void {
  const content = text || this.danmakuInputText;
  if (!content.trim()) return;
  
  const trackIndex = this.danmakuList.length % 5;
  const item: DanmakuItem = {
    id: `danmaku_${this.danmakuIdCounter++}`,
    text: content.trim(),
    color: this.selectedDanmakuColor,
    left: 100,  // 从右侧进入
    top: 8 + trackIndex * 6  // 轨道分配
  };
  
  this.danmakuList.push(item);
}
```

**位置更新**
```typescript
updateDanmakuPositions(): void {
  const now = Date.now();
  const deltaMs = now - this.danmakuLastTimestamp;
  const deltaPercent = (35 * deltaMs) / 1000;
  
  this.danmakuList = this.danmakuList
    .map(item => ({ ...item, left: item.left - deltaPercent }))
    .filter(item => item.left > -20);
}
```

aboutToAppear() {

### 4.3 性能优化

#### 4.3.1 弹幕性能
- 使用 `filter()` 及时清理超出屏幕的弹幕，避免内存泄漏
- 定时器间隔 16ms（约 60fps），平衡流畅度和 CPU 占用
- 弹幕数量无硬性限制，依赖自动清理机制

#### 4.3.2 氛围灯性能
- 光晕使用 `blur()` 而非阴影，GPU 加速渲染
- 颜色切换使用共享状态，避免重复计算
- 组件使用 `hitTestBehavior(HitTestMode.Transparent)`，不拦截点击事件

## 六、使用说明

### 6.1 弹幕功能使用

1. **发送弹幕**
   - 在底部输入框输入文字
   - 点击右侧"发送"按钮或键盘确认键
   - 文字将从右侧飘入视频画面

2. **选择颜色**
   - 点击输入框旁的"颜色"按钮
   - 在展开的颜色面板中选择
   - 选中颜色会显示在按钮上

3. **查看弹幕**
   - 弹幕从右向左平滑移动
   - 不同弹幕分布在不同高度轨道
   - 超出左侧屏幕后自动消失

### 6.2 氛围灯功能使用

1. **开启/关闭**
   - 点击视频下方控制栏的 💡 图标
   - 图标橙色表示开启，灰色表示关闭

2. **查看效果**
   - 开启后视频四边出现彩色光晕
   - 光晕颜色每 2 秒自动切换
   - 光晕不遮挡视频内容

3. **展开面板**
   - 开启状态下点击 ▶ 按钮展开面板
   - 面板显示当前颜色预览
   - 再次点击 ▼ 收起面板
